## 🟣 Sobre Mí

Soy **Samuel Vélez Guzmán**, Tecnólogo en Desarrollo de Software y estudiante de Ingeniería en Desarrollo de Software, con sede en Medellín, Colombia, enfocado en desarrollo **Backend**, **Full Stack** y **automatización de procesos**.

Cuento con experiencia construyendo aplicaciones web end-to-end en entornos productivos reales, desde el levantamiento de requerimientos hasta el despliegue, incluyendo diseño de bases de datos relacionales, autenticación por roles y prácticas de seguridad.

Trabajo con **Java, Spring Boot, Python, PHP y JavaScript** sobre **MySQL, PostgreSQL y SQL Server**, aplicando POO, arquitectura en capas, MVC, SOLID, Clean Code, Git e integración de APIs REST.

Actualmente curso el **Bootcamp Full Stack Junior Java de Generation Colombia** bajo metodologías ágiles (Scrum).
